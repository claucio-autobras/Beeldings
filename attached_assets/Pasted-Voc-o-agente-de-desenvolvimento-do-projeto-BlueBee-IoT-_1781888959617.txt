STACK
═══════════════════════════════════════════

Frontend: Next.js 14 + TypeScript + TailwindCSS + shadcn/ui (App Router, light mode exclusivo)
Backend: NestJS 11 + TypeScript ESM (imports SEMPRE com sufixo .js)
Auth: bcrypt + passport-jwt — JWT próprio com role + tenantId — SEM Supabase, SEM Replit Auth
ORM: Prisma 6
Banco: PostgreSQL 16 via Replit Database add-on (Neon nativo — zero configuração)
Timeseries: TimescaleDB 2.13 (disponível nativamente no Replit)
MQTT: HiveMQ Cloud via MQTT_BROKER_URL (externo)
Monorepo: Turborepo + npm workspaces + npm@11

SUA TAREFA AGORA — FASE 1
═══════════════════════════════════════════

Execute os passos abaixo EM ORDEM, um de cada vez. Após cada passo, reporte o resultado antes de avançar. Se encontrar erro, descreva o erro completo e aguarde instrução.

PASSO 1 — Verificar Node
  node --version && npm --version
  Esperado: Node v20.x e npm 10.x ou superior

PASSO 2 — Clonar repositório
  git clone -b develop https://github.com/claucio-autobras/BlueBee.git .
  (o ponto clona para o diretório atual)

PASSO 3 — Verificar estrutura
  ls apps/ && cat package.json | grep workspaces
  Confirmar que apps/frontend existe

PASSO 4 — Instalar dependências
  npm install
  Se houver conflito: npm install --legacy-peer-deps

PASSO 5 — Criar arquivo .replit
  Criar na raiz com este conteúdo:
  run = "npm run dev"
  entrypoint = "apps/frontend/src/app/page.tsx"
  [nix]
  channel = "stable-24_05"
  [ports]
  localPort = 3000
  externalPort = 80

PASSO 6 — Criar replit.nix
  Criar na raiz com este conteúdo:
  { pkgs }: {
    deps = [
      pkgs.nodejs_20
      pkgs.nodePackages.npm
      pkgs.openssl
    ];
  }

PASSO 7 — Configurar variáveis do frontend
  Criar apps/frontend/.env.local:
  NEXT_PUBLIC_API_URL=http://localhost:4000
  NEXT_PUBLIC_USE_MOCK=true

PASSO 8 — Subir o frontend
  cd apps/frontend && npm run dev
  Esperado: frontend rodando em :3000 sem erros
  OS MENUS EXISTENTES DEVEM APARECER CORRETAMENTE

PASSO 9 — Inspecionar e reportar
  Sem alterar nada, listar:
  - Quais rotas existem em apps/frontend/src/app/
  - Quais menus estão implementados
  - Quais páginas têm dados hardcoded
  - O que está com erro ou incompleto

PASSO 10 — Commit
  git add .replit replit.nix apps/frontend/.env.local
  git commit -m "chore: configurar ambiente Replit fase 1"
  NÃO fazer push ainda — aguardar revisão
